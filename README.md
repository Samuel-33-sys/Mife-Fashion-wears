# Mife's Wears — Vercel Demo

A responsive luxury-fashion storefront demo inspired by the supplied visual reference.

## 1. Install
```bash
npm install
```

## 2. Run locally
```bash
npm run dev
```
Open http://localhost:3000

## 3. Add your character images
Place your four character/model PNGs in:

- `public/images/character-1.png`
- `public/images/character-2.png`
- `public/images/character-3.png`
- `public/images/character-4.png`

Transparent PNGs work best.

## 4. Deploy to Vercel
Push the folder to GitHub, then import the repository in Vercel.

Framework: Next.js  
Build command: `next build`  
Install command: `npm install`

No environment variables are required for this front-end demo.

## Important
This is a front-end portfolio/client demo. The product buttons, account, search, cart, checkout, and newsletter are visual/demo interactions only. For a production store, connect them to a commerce backend such as Shopify, WooCommerce, Medusa, or a custom API.
